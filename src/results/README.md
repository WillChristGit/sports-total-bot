# Results Tracker for SportsTotalBot

Automatically fetches final NBA scores and compares them to daily picks to calculate performance metrics.

## Features

- **Multiple API Support**: Fetches scores from free APIs (balldontlie.io, TheSportsDB, RapidAPI)
- **Automatic Pick Matching**: Matches games to picks using team names and game IDs
- **Bet Type Support**: Handles totals (OVER/UNDER) and spread picks
- **Profit Calculation**: Calculates profit/loss based on American odds
- **Performance Metrics**: Tracks wins, losses, pushes, ROI, units, and win rate
- **Historical Tracking**: Saves results to JSON files for long-term analysis
- **Graceful Error Handling**: Continues working even if one API fails

## Installation

The tracker is included with SportsTotalBot. No additional dependencies required.

## Usage

### Command Line

```bash
# Track results for a specific date
./run_results_tracker.sh --date 2026-02-04

# Track the most recent picks
./run_results_tracker.sh --latest

# Generate a 30-day performance report
./run_results_tracker.sh --report 30

# Custom directories
./run_results_tracker.sh --date 2026-02-04 --picks-dir /path/to/picks --results-dir /path/to/results
```

### Python API

```python
from src.results.tracker import ResultsTracker

# Initialize tracker
tracker = ResultsTracker()

# Track results for a date
results = tracker.track_results(date="2026-02-04")
print(f"Wins: {results['summary']['wins']}")
print(f"Losses: {results['summary']['losses']}")
print(f"ROI: {results['summary']['roi']}%")

# Track latest picks
latest = tracker.track_latest_results()

# Get performance report
report = tracker.get_performance_report(days=30)
print(f"30-day ROI: {report['roi']}%")
```

## How It Works

### 1. Load Picks

Reads picks from `data/picks/daily_picks_YYYYMMDD.json` files generated by the main bot.

### 2. Fetch Scores

Attempts to fetch final scores from multiple APIs (in order):

1. **balldontlie.io** (free, no key required)
2. **RapidAPI NBA** (requires `RAPID_API_KEY` in `.env`)

### 3. Match Games to Picks

Matches game results to picks using:
- Exact game ID match (preferred)
- Team name matching (with normalization for abbreviations)

### 4. Evaluate Results

**For Totals (OVER/UNDER):**
- Compares actual total points to the line
- Determines win/loss/push
- Calculates profit based on American odds

**For Spreads:**
- Compares actual margin to the spread line
- Determines if the favored team covered
- Calculates profit based on American odds

### 5. Calculate Metrics

- **Win Rate**: Wins / (Wins + Losses) × 100
- **ROI**: Total Profit / Total Bets × 100
- **Units**: Half-Kelly Criterion based on EV
- **Profit/Loss**: Based on $1 stake per bet

## API Configuration

### balldontlie.io (Free)

No configuration required. Works out of the box.

### RapidAPI NBA (Optional)

Add to your `.env` file:

```bash

```

## Understanding the Metrics

### Win Rate

Percentage of non-pushed bets that won:

```
Win Rate = (Wins / (Wins + Losses)) × 100
```

### ROI (Return on Investment)

Percentage return on total bets:

```
ROI = (Total Profit / Total Bets) × 100
```

Assumes $1 stake per bet.

### Units

Recommended bet size using Half-Kelly Criterion:

```
Units = (EV / (Decimal Odds - 1)) × 100 × 0.5
```

Capped at 10 units max. 1 unit = 1% of bankroll.

### Profit/Loss

Actual profit or loss on a $1 bet based on American odds:

- **Positive odds (+150)**: Profit = (150 / 100) × $1 = $1.50
- **Negative odds (-110)**: Profit = (100 / 110) × $1 = $0.91

## Troubleshooting

### No picks found

Ensure `data/picks/daily_picks_YYYYMMDD.json` exists for the date you're tracking.

### No game results found

- Check that games have completed (status = "Final")
- Try a different API (if RapidAPI fails, balldontlie may work)
- Verify team names match (check normalization mapping)

### API errors

- **balldontlie.io**: May have rate limits. Wait a few minutes and retry.
- **RapidAPI**: Verify your API key is correct and not expired.

### Pending picks

Picks remain "pending" if:
- The game hasn't started yet
- The game hasn't completed
- No matching game was found
